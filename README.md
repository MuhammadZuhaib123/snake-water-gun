# Snake Water Gun Game 🎮

A simple **Snake, Water, Gun** game built with Python. The player chooses Snake, Water, or Gun, and the computer randomly selects its choice.

## 🛠️ Technologies Used

* Python
* `random` module
* Dictionaries
* Conditional statements
* User input

## 🎯 How the Game Works

The game follows these rules:

* 🐍 Snake beats 💧 Water
* 💧 Water beats 🔫 Gun
* 🔫 Gun beats 🐍 Snake
* Same choice = Draw

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python snake_water_gun.py
```

5. Enter:

   * `s` for Snake
   * `w` for Water
   * `g` for Gun

## 💻 Example

```text
Enter your choice: s
You chose Snake
Computer chose Water
You Win!
```
